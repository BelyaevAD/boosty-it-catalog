# История изменений

Все заметные изменения проекта будут отражаться в этом файле.

## Следующая версия

- добавлены стандартный GitHub Star widget с живым счётчиком и ненавязчивые призывы поддержать каталог в hero-блоке, отдельной плашке и футере;
- GitHub Mark взят из официального набора Primer Octicons и сопровождается лицензионным уведомлением;
- ключевые действия получили локальные SVG-иконки; внешний Star widget изолирован отдельным правилом CSP и sandbox;
- в репозитории появилась форма для предложений по развитию проекта;
- каналы получили несколько тематик: основная сохранена для совместимости, дополнительные доступны в фильтре;
- счётчики тем теперь динамически учитывают поиск, активность, цену и рост аудитории;
- каталог расширен за счёт публичного каталога Boosty, поиска по постам и русскоязычного индекса Common Crawl;
- добавлена очередь кандидатов с повторной проверкой ошибок и ранее неподходящих страниц;
- добавлены постоянные кураторские исключения и защита от публикации при массовой деградации Boosty API;
- публичные описания, заголовки и названия последних материалов очищаются от явных контактных данных;
- тематический охват расширен направлениями 3D/CAD, цифрового производства, hardware и DIY;
- добавлены очищенные описания каналов на основе профилей Boosty;
- подробности канала теперь открываются в модальном окне без ухода из каталога;
- отдельные страницы каналов сохранены для поисковой индексации и прямых ссылок;
- ссылка на Boosty перенесена к названию в таблице, отдельная колонка удалена;
- табличный вид стал основным, а девять колонок объединены в пять компактных смысловых групп;
- на узких экранах таблица превращается в вертикальные блоки без горизонтальной прокрутки;
- исправлены интервалы между фильтрами и результатами, активные фильтры стали интерактивными;
- «Быстрый выбор» стал многострочным блоком тегов без горизонтальной прокрутки и компактно сворачивается на мобильных экранах;
- мобильная панель дополнительных фильтров сворачивается, чтобы быстрее добраться до результатов.

## 1.0.0 — 2026-07-26

- опубликована исходная выборка из 227 русскоязычных IT-каналов;
- добавлен полный список из 312 найденных кандидатов;
- создан статический каталог с фильтрами, карточками, сравнительной таблицей и отдельными страницами каналов;
- добавлены sitemap, RSS, Schema.org и метаданные социальных сетей;
- настроены еженедельное обновление и публикация GitHub Pages.
